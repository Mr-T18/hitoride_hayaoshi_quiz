# 「ひとりで早押しクイズ」
## 制作：Mr.T(2023年：高専2年生の夏休み課題)
## ダウンロード方法
- Windows上でこのリポジトリをzipファイルごとダウンロードし、ファイルを解凍してください。
- .exeファイルを起動してプレイできます。
## ゲーム概要：
- 「ひとりで早押しクイズ」は、画面に表示される問題文を読み、ボタンを押して解答することで早押しクイズをプレイできます。
- イメージとしては、スマホゲームの「みんなで早押しクイズ」のような、1文字ずつ問題文のテキストが表示され、ボタンを押すことで問題文の表示がストップする、といったものを想定しました。
- 問題はすべて自作し、Excelファイルで管理しています。
## 操作方法：
- マウスまたはタッチパッドで画面上のボタンをクリックして操作します。
- スペースキーやEnterキーなどのキーボード操作には対応していません。
## ゲームモード：
- 「フリープレイ」は問題数と正解・誤答数に制限がなく、普通の早押しクイズとしてプレイできます。
- 「7マル3バツ」は7回正解するとゲームクリア、3回誤答するとゲームオーバーとなります。
- 「5 UP-DOWN」は5回正解するとゲームクリアですが、1回誤答すると正解のポイントは0に戻されます。2回誤答するとゲームオーバーとなります。
## ゲーム難易度(目安)：
- 「初級」は「誰でも考えればわかる」「多くの人が知っている」ような知識を想定した難易度の問題になっています。
- 「中級」は「知らない人もいる」「どこかで聞いたことはある」といった難易度の問題になっています。
- 「上級」は「ほとんどの人が知らない」「競技クイズをやっている人なら知っているであろう」という難易度の問題になっています。
